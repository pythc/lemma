# 引用定位、重复调度与自主 Lean 核验 · 2026-10-19

## 用户确认的产品方向

取消强制人工语义确认。由 Agent 阅读原文、独立复核形式化含义、选择证明或反例、决定补库及修复。语义决策记录为 AI 判断，不伪造人工签名；Lean 检查和公理审计才决定机器核验状态。结果查看确认仅控制界面展示。

## 引用定位

严格定位器不放宽数学符号或公式。新增确定性修复器：同一固定上下文中只有一处逐字匹配时纠正错页；短引句重复时，只能通过源文本哈希及准确位置、或唯一的固定命题范围消歧，并扩展为可独立定位的原文。没有唯一依据时返回带上下文的候选位置，不能选最近项或第一项。原始模型输出、修复方法及新证据版本均保留。

实际 ε-band 翻译中的三处错误可确定性修复：两条重复“ε > 0”定位到完整命题；“called ε-band”从第三页纠正到第四页。Lean 目标不变。

## 调度收敛

规划只对完成、未解决或子核验状态改变等有效证据触发；中间失败产物、诊断结果与规划结果本身不触发重复规划。无新证据、无活跃任务时汇总或等待实际子任务，不继续空转。

同一错误第二次出现时停止该修复路径。已知非瞬时文献 HTTP 响应（例如 202、403、404）不通过模型反复请求同一地址。按规范化 URL/题名识别重复文献任务，改变节点标题或前置依据不能绕过去重。异步 202 不假定已取得全文，也不凭猜测执行未知轮询协议。

## Agent 自主语义决策

真实复核节点 assess_target 读取不可变原文、固定 Lean 目标、六类翻译对照及已有发现，选择 proof、counterexample、retry_translation、recover_domain 或 unresolved。proof 表示启动证明搜索，不要求已有证明；counterexample 表示开始反驳搜索，不等于已经反驳成功。

放行仍校验精确 targetHash、semanticArtifact、每一条歧义处理记录及实际模型证据。核验方向与 Agent 决策一致。证明产物连接到语义决策证据；重放检查此链。旧人工确认记录保持原样，旧历史不会因服务启动自动迁移成新的付费任务；当前轮在显式恢复时使用新策略。
