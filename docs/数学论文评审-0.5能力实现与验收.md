## 执行与数据流

R02 固定原文 → R02C 选取上下文 → R03 翻译与对照 → R05 固定合同 → R04T 类型检查 → R04K 核对库定义 → R04 回译/差异 → 记录确认 → R06 原证明候选审计 → R07/R07C 定理与案例检索 → R09 候选 → R10 Lean 检查；失败按诊断进入下一候选。人工翻译路径仍执行类型检查和规则审阅，必须记录核对依据。

每个任务保存内容寻址产物，输入引用上游摘要。每轮修复记录目标摘要、候选、检查、差异、诊断与累计耗时。原证明审计失败保留单独错误，不抹去独立证明流程。翻译复核服务故障可以保留目标创建新任务重试，旧错误始终保留。

## 运行与预算

本地页面 http://127.0.0.1:4178/ ，API 仅监听 127.0.0.1:4179。使用固定 Lean 4.35.0、mathlib 提交 56a005855ea17e0b0958f73ec801ae140b0a1679 及已锁定依赖。代码保存于 math-review-bot，命令见 README。

模型为用户指定的 OpenAI 兼容本机接口，显式请求 high，实际返回强度单独记录。证明阶段 3 次模型调用、24000 预留输出 token、180000 输入字符；预留值不等同实际计费 token。单次模型最多 300 秒，本轮证明总预算 12 分钟。翻译和原证明审计不包含在证明修复计数内。模型输入可能包含论文及补充原文，应按实际接口数据处理规则使用。

## 评价口径

31 条人工编写参考命题分成 20 实分析、5 线性映射、6 数论/计数，正例、否定证明和未完成项全部保留。7 条翻译结构样例含 5 个故意错误和 2 个忠实对照。它们测量执行与已知规则行为，不是自然模型误译率。每次报告记录源文件摘要；代码变化后页面显示待重新核验。

研究候选仅建立来源记录：[Soft Uniform Spaces, Universal Relations, and Čech-Type Soft Proximity](https://arxiv.org/html/2602.19106v2)，自定义结构与当前域配置有差异，未做专家金标准标注，也未复制或宣称核验全文。参考 [Lean 官方证明验证说明](https://lean-lang.org/doc/reference/latest/ValidatingProofs/)区分形式命题成立与数学意图忠实性。

尚未完成的研究能力：独立专家标注、真实研究论文总体评测、自动证明步骤组合、新定义自动保真形式化、自动外部引用获取、扫描公式 OCR 和全面跨论文修订影响分析。不得用工程测试通过替代这些验收。
